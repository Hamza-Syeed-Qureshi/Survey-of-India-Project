# Survey of India Multi-State Station Data Analysis

## Overview

This project focuses on processing and analyzing Survey of India
station data from multiple states and regions.

The workflow includes data loading, date filtering, date extraction
from file paths, station code extraction, file metadata processing,
and data transformation using Python.

## Technologies Used

- Python
- Pandas
- NumPy
- Regular Expressions
- Jupyter Notebook

## Key Operations

- Data loading
- Data cleaning
- Data transformation
- Date extraction from file paths
- Station identification
- File metadata processing
- Missing file analysis
- Station-wise analysis

## Dataset

The original Survey of India dataset is confidential/restricted
and is therefore not included in this repository.

The code was developed and tested using authorized data available
in the local working environment.

The dataset is not redistributed through this repository.
